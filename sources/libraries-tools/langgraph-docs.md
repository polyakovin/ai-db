# LangGraph Documentation

Официальная документация LangGraph — low-level orchestration framework и runtime для long-running stateful workflows и agents.

## Описание

- **Основные темы:** state graphs, persistence, durable execution, interrupts, memory, streaming и deployment.
- **Практическая ценность:** отделяет runtime-уровень LangGraph от более высокоуровневых agent frameworks и harnesses.
- **Relevance:** источник фактов для архитектур с явным состоянием, возобновлением и human-in-the-loop.
