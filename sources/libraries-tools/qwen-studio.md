# Qwen Studio

Официальное веб-приложение Qwen от Alibaba Cloud для интерактивной работы с моделями семейства Qwen.

## Что подтверждено

- Qwen Studio доступен по адресу `chat.qwen.ai`.
- Сервис представлен как официальный Qwen App и имеет web/mobile интерфейсы.
- Конкретная модель и доступные режимы могут меняться без сохранения стабильного URL для каждой конфигурации.

## Практическая ценность

Qwen Studio полезен для ручной проверки поведения актуальных Qwen-моделей до интеграции через API: можно быстро оценить язык, формат ответа, мультимодальность и пригодность для задачи. Для воспроизводимого сравнения результаты нужно переносить в локальный eval-набор, фиксируя модель, дату и prompt.

Сведения о продукте перенесены в [canonical-заметку Qwen](../../tools/platforms/qwen.md).

## Ограничения источника

- Главная страница почти не документирует limits, data handling и состав функций.
- Для API, лицензий и self-hosting нужно обращаться к официальной документации и репозиториям QwenLM, а не выводить их из возможностей consumer app.
